# assets/

Local, offline assets for the course. Diagrams in this course are authored as
**inline SVG directly inside the module HTML** (see Modules 1 and 8) and the
theme uses **system font stacks**, so no image or font downloads are required.

Keep this folder for any future local assets (icons, additional inline-SVG
sources). Everything here must be local — no CDN links or external downloads —
so the site keeps working over `file://` and fully offline.
